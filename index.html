Keep the test set untouched.

Split before fitting imputers, scalers, encoders, feature selectors, or PCA. Fit preprocessing on training data only; use that fitted pipeline to transform validation and test data. This prevents leakage and makes the final score meaningful.

02 / Let the data guide you

Pick tools for the job

These are decision guides, not rules. Compare a simple baseline with more complex models using the same split and appropriate metrics.

What does your dataset look like?

Check this before choosing transformations or an estimator.

Numeric columnsScale for distance/linear methods; trees usually do not need it.
CategoriesOne-hot for nominal values; ordinal encoding only when order is real.
Missing valuesMeasure first; impute or omit with a reason, fit on training data.
Dates and mixed fieldsExtract meaningful date parts; split structured text into useful features.
Extreme values / skewInvestigate first; transform or cap if justified—do not delete by default.

Which model should you try first?

Begin with an interpretable baseline; add complexity only when it helps.

Number → regressionLinear baseline → multiple / polynomial → regularized linear model.
Category → classificationLogistic baseline → random forest / AdaBoost / gradient boosting.
No target → clusteringScale numeric features → K-means; inspect whether clusters are useful.
Many correlated featuresConsider PCA after scaling; keep it inside the training pipeline.
